# Mala Eramma — Digital Portfolio

This is a browser-ready, static reconstruction based on the publicly accessible portfolio at:
https://slick-dev-pages.lovable.app/

## Run in Visual Studio Code

1. Extract this ZIP.
2. Open the extracted `mala_portfolio_reconstruction` folder in VS Code.
3. Open `index.html` in a browser.

Recommended: install the **Live Server** extension in VS Code, right-click `index.html`, and choose **Open with Live Server**.

No npm installation or backend server is required.

## Included
- `index.html` — portfolio content and sections
- `styles.css` — responsive dark/blue visual styling
- `script.js` — navigation, toolkit tabs, project filters, rotating role text, and contact email action

## Important accuracy note
This is a reconstructed static project based on the live website's visible content and layout. It is not the original Lovable React/Tailwind source project. Some visual details, original images, exact animations, and original hidden implementation may differ from the published website.

The certificates and toolkit removals requested in the conversation have been applied to the reconstructed version.
